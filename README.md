# Heart Disease Risk Stratification — End to End ML Project

A full end-to-end machine learning project predicting heart disease risk using the UCI Heart Disease dataset.

## Project Structure
- **Phase 1** — EDA & Feature Engineering
- **Phase 2** — Unsupervised Learning (K-Means, DBSCAN, PCA)
- **Phase 3** — Supervised Learning (7 algorithms, Cross Validation, Hyperparameter Tuning)
- **Phase 4** — Ensemble Learning (Voting, Stacking, Optuna)
- **Phase 5** — Model Explainability (SHAP) *(in progress)*

## Key Results
- Best Model: Logistic Regression
- F1 Score: 0.830
- ROC-AUC: 0.913
- Recall on disease class: 89%

## Tech Stack
Python, scikit-learn, imbalanced-learn, XGBoost, Optuna, SHAP, FastAPI
